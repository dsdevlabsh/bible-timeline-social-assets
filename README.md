# Bible Timeline — social image assets

Public image assets for the Bible Timeline Instagram auto-publisher.

**Images ONLY.** No captions, prayers, post metadata, or code ever land here — those stay in the private `dsdevlabsh/scripture-timeline` repo. Files are named by content hash (`images/<sha256-16>.png`) and served via raw URLs to the Instagram Graph API, which requires a publicly reachable `image_url`.
